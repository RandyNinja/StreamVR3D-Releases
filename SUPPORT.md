# Support

No public StreamVR3D build is available yet. After the first approved release, use the [installation guide](docs/installation.md) and [troubleshooting guide](docs/troubleshooting.md) first.

For installation problems and app bugs, search existing GitHub issues and open a report using the appropriate template. Include the app version, Quest model, Windows version if relevant, and steps to reproduce. Describe the error in your own words; do not paste unreviewed logs, credentials, private addon URLs, or account details.

For security concerns, follow [SECURITY.md](SECURITY.md) and use the private report form. Feature requests can use the feature request template. Community help is best effort.
