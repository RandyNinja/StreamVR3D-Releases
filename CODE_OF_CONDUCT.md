# Community conduct

Be respectful and constructive. Harassment, hate, threats, doxxing, scams, malicious links, spam, and instructions to access content without authorization are not welcome.

Do not post credentials, private addon links, personal information, or suspected security vulnerabilities in GitHub issues or Discord. Use the private route described in [SECURITY.md](SECURITY.md) once it is enabled for security reports.

Moderators may remove harmful posts, warn members, apply timeouts, or ban accounts. Serious or repeated harm may lead to a ban without an earlier warning. Contact a server moderator privately to appeal a Discord moderation decision; use GitHub's report controls for abuse in GitHub issues.
