# Security reporting

Please report suspected StreamVR3D vulnerabilities privately. In this repository, open **Security → Report a vulnerability** to use GitHub private vulnerability reporting. Do not post exploit details, credentials, private addon links, device identifiers, or personal logs in public issues or Discord.

Include the affected app version, steps to reproduce, the observed result, and the likely impact. Redact tokens, usernames, provider URLs, and local paths. The publisher will review reports and coordinate fixes where possible; no fixed response time is promised.

If the **Report a vulnerability** button is unavailable, the private reporting route has not been enabled. Do not put vulnerability details in a public issue; the repository owner must enable private vulnerability reporting before this page is published.
