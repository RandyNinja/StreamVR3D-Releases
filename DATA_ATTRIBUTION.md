# 3D film index attribution

StreamVR3D includes a small offline index of candidate 3D film titles for discovery. The index contains title names, years, identifiers, genre labels, and limited format facts. It contains no film files, streams, posters, or other artwork. A title's presence does not mean that a playable 3D copy is available or that the user has access rights.

The offline index was compiled using the Wikipedia contributors' [list of 3D films (1914–2004)](https://en.wikipedia.org/wiki/List_of_3D_films_(1914%E2%80%932004)) and [list of 3D films (2005–present)](https://en.wikipedia.org/wiki/List_of_3D_films_(2005%E2%80%93present)), together with Wikidata identifiers and genre labels. The lists were checked on 24 September 2026. The offline index retains 538 candidates linked from the film tables on those pages. Each candidate links to the list on which it appears. Another 37 earlier candidates were set aside for individual review because neither list supplied a matching film-table link. The project selected, normalized, and combined these facts; errors or omissions are possible.

The displayed 3D release catalogue also uses evidence fetched at runtime from [xREL's 3D release feed](https://www.xrel.to/movie-3d-release-list.html) and [3DIQ's on-disc list](https://3diq.app/on-disc). xREL entries are considered when they have an IMDb identifier and a recognized stereo-format marker. The app resolves English display titles by identifier using [Cinemeta](https://v3-cinemeta.strem.io/); 3DIQ entries are matched by title and year. These live sources are cached on the user's device and are not embedded in the offline index. A catalogue entry indicates release evidence, not that an installed addon supplies a playable source.
